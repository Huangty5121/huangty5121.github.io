# 独立桌面 demo · 2026-09-14

预览：[新桌面](http://127.0.0.1:8772/table/#home) · [组织索引](http://127.0.0.1:8772/table/#background)

这是独立实现，不再加载旧版的 home.css、desk.css 或其叠加样式。旧 desk.html 留作对照；没有删除旧版或替换其入口。新版不是已经定稿的作品，也没有发布。

## 这一版的设计判断

首页是两组有主次的物件，不是等间距散开的入口卡片。左侧文件夹承载学习与经历，论文和材质照片叠在其上；右侧是蓝色播放器与氧化金属上的半透明便笺。红、蓝是局部颜色，桌面与数字文字保持中性。阴影主要说明接触与遮挡，只有短笔记使用干涩笔画；正文不做模糊。

初版 Background 的「大标题、四个分区、白纸上的三排履历」已放弃，也清除了它的闲置样式。新的入口是组织标记索引：学校在前，默认选中 PolyU；右侧同时显示学习与该组织的多段经历。组织切换只更新阅读内容，不重新排列标记。从桌面进入索引时，理大标记在两个位置之间移动，建立空间对应；减少动态效果模式下不播放该过渡。

手机保留同一组桌面物件，重新组合成长桌面，没有固定播放器条。经历页先显示学校、再显示所选内容；其他组织可展开，选中后移动到相关记录并把阅读焦点交过去。按时间检索是另一个入口，会员与证书单独说明语义，均不伪装成任职。

## 内容和交互结构

| 入口 | 内容 | 操作 |
| --- | --- | --- |
| 学习与经历 | 12 个组织，3 段学习，16 段经历 | 组织选择、相关记录、按时间与类别检索 |
| 论文与项目 | 8 个已有条目 | 类别、搜索、详情、原始来源链接 |
| 论文阅读 | 3 份本地预印本 | 站内阅读、独立打开、下载所列版本 |
| 笔记 | 2 份整理稿 | 列表与阅读，保留待本人确认说明 |
| 材质示意 | 4 张生成图 | 查看大图，不宣称为个人作品或照片 |
| 音乐 | 陈奕迅《尘大师》官方试听 | 页面直接播放、暂停；换页不重启音频 |
| 外观 | 中英文、明暗、100/115/130% 字号 | 偏好保存；纸张、粗糙笔画、阴影、雾度可调 |

同一段联合实习可从两个组织进入，但引用同一个记录 ID。研究与工作类别可交叉，也不复制成两项成果。所谓「当前参与」保留 CV 所列任期的限定，不当作实时在职核验。

这轮重用的是现有 CV/来源资料，没有重新确认外部出版状态或任职变化。未收录的证书凭证、个人照片和文字仍需补充；不从私人情绪对话中新增公开内容。

## 文件怎么改

- `dist/table/config.mjs`：首页精选条目、名字、短介绍、音乐。音乐继承旧配置，也可在这里覆盖；本地音频路径相对此目录解析。
- `dist/desk-data.mjs`：论文、项目、经历、笔记、示意图的唯一内容记录。
- `dist/desk-background.mjs`、`dist/desk-affiliations.mjs`：学习、组织关联与资格记录。新版只导入数据，不调用旧排版函数。
- `dist/table/table.mjs`、`table.css`：新版交互及唯一的排版样式。

这里的配置是公开静态文件，不是私有后台，不要填写密钥或私人材料。访问者没有修改歌曲与个人内容的表单。

手写字有独立的当前用字子集 `wenkai-table.woff2`，授权沿用 `dist/assets/OFL-WenKai.txt`。以后新增子集之外的汉字时，浏览器会回退完整 WenKai，保持字形一致；若经常增加新短句，应重新生成子集，避免重新加载约 6.9 MB 的完整字体。

## 核验与实际画面

测试脚本：`table-check.mjs` 与 `table-live-check.mjs`。最新结果保存在 `table-review/checks.json`、`table-review/live-checks.json`，不要用旧 desk 的测试代替。

覆盖内容关系、入口遮挡、360/390/540/768/1024/1440px 布局、中英文、暗色与大字、触控、键盘/焦点、设置持久化、未找到页面、减少动态效果、真实 PDF 响应、本地资源请求和音频失败状态。外部音频另做实际播放及跨页持续播放测试，不把模拟失败测试当成真实试听成功。

实际截图在 `table-review/`：`home-desktop.png`、`background-desktop.png`、`home-390.png`、`background-390.png`、`home-dark-large.png`、`background-dark-large.png`。生成参照为 `home-reference.png` 和 `atlas-reference.png`；完整提示词及被放弃的方向记在 `TABLE-PROMPTS.md`。

## 视觉复核中的取舍与未完成项

实际检查后，缩小了挡住经历入口的照片/论文范围，露出文件夹标题和徽章；移除了文字标记重复的名字；重排九个其他组织，避免孤零零的第三排；手机默认收起其他组织，让学习信息更早出现；去掉整页焦点边框和长页面纹理断层。这些修改针对的是可观察的问题，不以「少放东西」作为审美依据。

这一版的长处是物件重叠有明确入口、信息能沿关联读下去，且没有把所有内容堆到首页。它的短板也明确：徽章有成品渲染和原始标记两种质感，精细度不一致；黑色模式下深色标记的视觉分量偏弱；论文封面与生成金属照片在语义上并无研究关联，仅为不同入口共处桌面的设计示意。没有用连线暗示它们有学术关系。

因此这份是用来检验构图、导航与阅读关系的可操作稿，不能据此宣称已达到最终产品的艺术完成度。下一次判断应针对这些具体差距，而不是继续堆叠新的物件或形容词。
