# Field Cabinet prompt set

## Primary mesh material

```text
Use case: photorealistic-natural
Asset type: reusable website material photograph
Primary request: A high-resolution editorial macro photograph of one continuous piece of loosely folded translucent off-white open-weave gauze. Individual fibers, imperfect thread intersections, frayed micro-fibers and material translucency must be visible.
Scene: pale mineral grey-green plaster with large quiet negative space.
Composition: horizontal crop; mesh occupies about 70% of frame and exits naturally at two edges; no centered product pose.
Lighting: large soft daylight from upper left, physically plausible contact shadows and gentle falloff.
Style: photorealistic museum-catalogue material study, calm and analytical.
Avoid: text, pins, frames, borders, logos, watermark, plastic gloss, dramatic spotlight, artificial blur, CGI.
```

## Contrasting metal material

```text
Use case: photorealistic-natural
Asset type: reusable secondary website material photograph
Primary request: An art-directed close photograph of three overlapping oxidized sheet-metal planes and one narrow translucent tracing-paper edge. Include one circular punched hole.
Composition: strong diagonal geometry; dense material in the right two-thirds and a calm shadow field on the left.
Lighting: raking side light revealing matte oxidation, scratches, dust, edge thickness and soft cast shadows.
Palette: muted vermilion, dark iron, oxidized copper green, charcoal and warm grey.
Avoid: text, people, logos, watermark, machinery, decorative props, glossy product photography, heavy blur, CGI.
```

## Index page

```text
Use case: ui-mockup
Asset type: desktop Index page for an object-led personal website
Primary request: A shippable 16:9 retrieval page on a pale grey-green mineral field with faint orthographic grid. Keep identity tiny. Use a thin title ALL OBJECTS, an oversized outline bracket, one underlined search field, a vertical text/image/project filter rail, and six spacious object rows. Each row contains sequence, title, quiet type metadata and a precise thumbnail. The active row A TOOL FOR SEEING gains a vermilion rule and reveals a large offset mesh crop behind the list.
Style: exhibition index and architect's catalogue; Swiss sans with small mono metadata; hard edges and hairline rules.
Interaction: hover image reveal and travelling underline.
Avoid: cards, rounded rectangles, bento, dates as structure, resume chronology, sticky-note collage, gradients, glassmorphism, fake institutions.
```

## Detail page

```text
Use case: ui-mockup
Asset type: desktop content-detail page
Primary request: A shippable 16:9 detail opening for A TOOL FOR SEEING. Pale grey-green mineral background; huge mesh image cropped from the left edge; three-line title high on the right; one short serif abstract; compact two-column metadata separated by hairlines; a narrow NEXT OBJECT strip using the vermilion metal image. A large thin bracket links image, title and metadata without enclosing them.
Metadata: FORM PROJECT; MEDIUM MIXED; STATUS ONGOING; ROLE AUTHOR.
Style: architect's monograph and exhibition object record, refined Swiss typography.
Interaction: image expansion, bracket draw-on, underlined OPEN NOTES.
Avoid: cards, pills, chronology, fake affiliations, dashboard UI, bento, gradients and glassmorphism.
```
