# 个人网站完整设计图纸 · V1

日期：2026-09-09。状态：结构设计提案，可评审；不是已实现的网站。

打开同目录 `index.html` 可查看 12 张设计图纸。图中方框、图形和文字是明确的线框占位，不是材质成品；没有将虚构项目、尺寸、实验数据或身份写成用户事实。

## 01 设计判断

前几轮建立了材料气氛，但把个人网站逐渐收窄成单个实验的陈列。现在纠正以下结构：

- 首页承载一个人的多种内容；项目、文字、照片可以独立存在，不强制归入某条主题线索。
- 首页的空间构图有人工编辑判断，自动排版负责适配，不负责发明意义。
- 首页直接提供姓名、短介绍、必要的当下身份/关联和联系入口。教育、经历等可以出现在介绍或内容上下文，不各占一个首页章节。
- 物件形态是呈现选择，内容类型是语义，两者分开。文章不自动等于纸张，项目不自动等于金属。
- 页面关系线表达真实内容关系；图片细节注释属于详情中的媒体组件。主页不伪造工程尺寸，不强迫每个项目都配实验图。
- 材质有自己的视觉语言，但阅读文字仍须清晰、可选取、可翻译、可放大。

## 02 全站结构

第一版只有三种核心路由，另加一个全局信息层。

| 位置 | 地址 | 作用 | 到达与返回 |
| --- | --- | --- | --- |
| 首页 | `/` | 个人身份 + 精选内容的自由编排 | 从姓名返回，保留原滚动位置 |
| 全部内容 | `/index` | 全量内容的文字索引、搜索、筛选 | 从全局导航进入；筛选写入 URL |
| 内容详情 | `/entry/:slug` | 按内容需要组合正文与媒体 | 首页物件及其标题进入同一地址；索引也进入同一地址 |
| 关于与联系 | 任一页 `#about` | 更完整的介绍、少量经历、公开联系方式 | 全局按钮打开；关闭回到原页面与触发位置 |
| 媒体查看层 | 详情内 `#media=<id>` | 查看大图、图集、视频和局部注释 | 从正文媒体进入；关闭返回原段落 |
| 找不到内容 | 未匹配地址 | 说明内容不可用，提供首页/索引 | 不渲染空白画布 |

示意 URL 约定：`/index?q=...&type=...&tag=...&sort=updated`。语言使用同地址的 `lang=zh|en`，这样首页、索引和详情都可直接分享指定语言；界面首次进入默认遵循已保存的选择，再考虑浏览器语言。文章只提供一种语言时，明确提示原文语言，绝不伪装成已翻译。

`#about` 与 `#media=<id>` 为互斥浮层状态。通过浏览器后退先退出浮层，再返回来源页。直接打开带浮层地址时，关闭用替换当前历史记录的方式移除 hash，避免后退到站外。

不新增项目、论文、照片、教育、经历等独立首页分区或顶级路由。需要找这些内容时，通过索引筛选。合集使用可选 `collectionIds` 和对应筛选 URL；初版不要求单独合集页面。

## 03 首页的阅读与摆放

### 身份带

姓名、两行以内短介绍、必要的当下关联、联系入口直接可见。它与内容在同一表面，约占桌面首屏上方 120–160px；不是全屏自我介绍，也不是必须点击才知道身份的谜题。没有提供的真实信息保持待填。

### 内容场

以 1440px 桌面为首个构图基准：左右留白约 64–88px；内部参考 12 列，但物件不显示统一卡片边框。不强求所有内容塞满一个屏幕。初始可选择 4–6 条精选内容组成一幅构图，更多精选组成下一个自然滚动的构图单元；优先给媒体和标题足够空间。

每个构图单元预设 1 个主视觉、2–3 个中小入口及 0–1 个纯文字入口。主视觉由可读性、媒体比例和编辑意图共同决定，不等于“最重要的人生经历”。不按类别永久绑定左、右区域。

首页物件显示实际标题、简短语境和必要的日期/地点。它们是局部说明，不把页面变成按年月排列的简历。标题即使不悬停也可读。只使用“PHOTO”“NOTE”或连续编号作为入口名称不合格。

关系线默认少量显示或不显示；有真实关系时才绘出。点击/聚焦一个物件可显露它的关联说明；其余内容仍可读。没有关系的内容自然独立存在，不需要人为编组。

### 构图约束与增量

1. 编辑者选择内容与代表媒体；没有媒体的内容用文字，不自动生成假照片。
2. 内容量与宽高比选择适合的已设计构图；首版使用少量确定模板，不做随机数种子或力导向图。
3. 物件与标题共同占据一个布局区域，标题排入文档流。重要文字不得被其他物件覆盖。
4. 允许少量有意的媒体重叠；边界、标题、点击目标仍可区分。无意义的叠放不增加信息。
5. 测量真实文字高度，满足间距后再绘制注释。空间不足先增高构图，再重排，最后才减少本单元项目数；不缩小文字解决溢出。
6. 悬停不改变物件尺寸、位置或全局布局，避免目标逃离指针。只有点击后才发生跨页面过渡。
7. 新内容默认进入索引；标记为精选后进入下一个适配位置。已有内容不因一次悬停或刷新而重新洗牌。

## 04 交互状态

| 事件 | 可见变化 | URL / 焦点 / 回退 |
| --- | --- | --- |
| 默认 | 标题与导航清晰，保留材质层次 | 按内容顺序提供链接 |
| Hover / focus | 标题下划线、轻微阴影、可选关联线出现；物件位置不动 | 不改变 URL，不隐藏必要信息 |
| 点击物件或标题 | 进入同一内容详情；可做 180–280ms 克制过渡 | 更新地址；焦点移到内容标题 |
| 点击关联标题 | 打开被指向的内容 | 普通语义链接，可以新窗口打开 |
| 点击详情媒体 | 打开查看层，显示大图与图注 | 保存段落位置；Esc/关闭返回 |
| 返回首页或索引 | 恢复来源滚动与索引筛选 | 恢复触发入口的焦点 |
| 点击关于与联系 | 打开信息面板 | 键盘焦点移入、限制于面板；关闭后恢复 |
| 减少动态效果 | 直接切换或短淡入，无视差 | 所有内容与导航能力不变 |

不让拖拽物件成为浏览前提。局部拖动或 3D 光照是后续可选实验，不是首版架构依赖。触摸设备单击直接进入详情，不要求“第一次点击模拟 hover、第二次再打开”。

## 05 内容详情：同一骨架，按内容安排

详情统一包含返回来源、标题、简述、实际元信息、正文媒体、相关内容、联系与全局导航。元信息只显示已提供字段；角色、机构、时间等作为内容语境出现，不机械排成履历。

### 项目/实践型

开头保留首页代表媒体的身份与材质。后续自然向下滚动，按实际内容使用文字段落、单图、图组、过程片段、嵌入演示、下载链接。图纸上标出的“缘起/过程/结果”为可选块示例，不要求所有记录都遵循同一叙事模板。正文最大约 68 个拉丁字符宽；宽图可以跨过正文栏。

### 文字型

标题、摘要、作者提供的日期、清晰的正文阅读栏优先。背景纹理弱于首页；不把所有正文烘焙进一张旧纸图片。侧边短注释仅在宽度充足时出现，窄屏归入相关段落。没有封面也可以正常成为首页入口。

### 照片/图集型

照片成为页面主角，图注、日期地点和故事文字按实际数据出现。一个图集是一个内容条目，多张照片作为媒体子项。媒体查看层提供上一张、下一张、计数、关闭、键盘与触摸操作；不默认自动播放。

### 短记录/外链型

短内容可以只有一段文字或一张图。若只有外链，首页标题标记外链并直达，不生成一张空洞的详情页。外链行为须在数据中明确，不伪装为站内导航。

## 06 全部内容索引

索引复用同一批条目，不维护第二份内容。初始按编辑排序或更新时间，用户可切换；类型、主题与时间为筛选条件，不变成首页章节。

桌面使用清晰的标题行、类型/时间等少量元信息及可选预览。每行只有一个主要目的地。手机把次要信息放到标题下方，不横向缩成小字表格。搜索零结果给出清除条件按钮；无媒体的条目不显示破图占位。筛选和查询应可分享并被后退恢复。

## 07 关于、联系和少量经历

首页已经提供姓名、短介绍、必要关联和联系入口。关于面板只是增补：较长介绍、少量教育/经历、公开邮箱或社交链接、经用户提供的可下载文件。只有两三条教育信息时，使用几行自然文字或紧凑列表即可，不设置一个空旷页面。

联系默认使用明确标注的公开邮箱链接与用户实际提供的社交链接，不先引入留言表单、后台收件和垃圾信息防护。文件或联系方式未提供时不展示可点击假按钮。

## 08 响应式、语言、主题与字号

| 条件 | 设计行为 |
| --- | --- |
| 宽桌面 ≥1200px | 完整分布式构图，独立注释空间 |
| 中等宽度 768–1199px | 减少跨栏/重叠，两列或较松的纵向构图 |
| 手机 <768px | 按编辑顺序纵向展开，图像保持不同大小与比例，文字按正常流排布；跨物件连线变成就近文字关联 |
| 中文 / 英文 | 翻译标题、说明、导航分别存储；重新测量文字高度、重排，保持内容顺序与关系 |
| 缺少翻译 | 显示可用原文并说明语言，不自动声称已翻译 |
| 标准字号 | 正文建议 18–20px，说明至少约 14px；中文约 1.65–1.8 行高 |
| 大字号 | 正文与说明同步放大约 15%，允许构图变高或变成更少列 |
| 特大字号 / 浏览器缩放 | 正文与说明放大约 30%；保持浏览器 200% 缩放可用，允许切换成流式排版 |
| 暗色 | 背景为低噪声炭灰，文字明亮可读；纸张、照片保留本身颜色 |
| 明色 | 同一内容顺序与构图，背景为暖灰白；照片不做颜色反相 |
| 低动态偏好 | 不使用视差或跨屏大幅移动；链接和阅读照常工作 |

字体：数字界面使用一个兼容中英文的无衬线字体家族/回退系统，靠字号、字重和留白分层。物件内的手写、刺绣、蚀刻是素材自身内容；必要文字另外提供可读文本，不承担唯一导航。

交互区域目标约 44×44px，焦点样式清晰。正文对比度目标至少 4.5:1；图案、线条、颜色不能是唯一的信息通道。上述是实现验收目标，当前线框不能证明无障碍合规。

## 09 组件与内容数据

建议使用以下分离结构；这是设计契约，未锁定框架或内容管理工具。

| 数据 | 必要字段/职责 |
| --- | --- |
| Profile | 姓名、各语言介绍、实际关联、公开联系链接 |
| Entry | 稳定 ID、slug、类型、各语言标题/摘要、日期、主题、正文块、目的地 |
| Media | 来源、宽高、替代文字、图注、焦点区域、可选细节锚点 |
| Relation | from、to、明确关系文字、可选端点；不存在就不绘线 |
| Collection | 可选的人工合集；不要求每条内容归组 |
| HomeSelection | entryId、代表媒体、呈现方式、相对权重、编辑顺序；独立于内容正文 |
| Presentation | photo-print / instant-photo / paper / text / object；材料资源与裁切规则 |
| Preferences | 主题、语言、字号、动态偏好；本地保存，无需账号 |

关系例子是“这篇记录补充了该项目”“这张照片来自这篇文章”，不能以“两件东西都是金属”推断同一研究。

前端建议分为 SiteShell、Identity、ContentField、EntryLink、MaterialSurface、Caption、RelationOverlay、EntryRenderer、MediaViewer、ContentIndex、AboutPanel、Preferences。页面可索引、正文可读、链接可用是基础；材质和动画在其上增强。图片生成仅用于经确认的视觉素材，禁止生成内容事实。

新条目的最小输入是标题、内容或目的地、类型。图片、材质、关系、合集都是可选项。首页选择独立设置，模板缺少支持时优先回退到文字/图片排版，不产生空白物件。

## 10 状态覆盖与实施验收

必须覆盖：零内容、单条内容、数十条内容、无封面、长标题、仅一种语言、无关联、外链、图片加载失败、媒体加载中、索引零结果、失效地址、直接进入详情、直接打开浮层、浏览器后退、大字号、手机、键盘、低动态偏好。

下一阶段应制作同一组经确认的内容在首页、详情和索引里的可点击原型，验证上述状态后再做高保真材质。该顺序解决的是内容一致性、点击目的地和响应式排版，不能以多生几张首页图代替。

当前交付范围：12 张可交互翻阅的架构线框图纸、此设计说明。浏览器内的线框导航/查看功能服务于评审，不代表生产网站功能已开发；图纸中的身份/文章/照片均为内容角色占位。此前生成的图片仅作为气氛参考，未被认定为真实内容或最终版式。
