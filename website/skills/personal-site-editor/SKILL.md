# Personal site editor

The active site is generated by `website/build.mjs` into `material-demo/dist/site/`. Edit source files in `website/`; do not edit generated HTML. Read [architecture.md](../../architecture.md) for source ownership, shared layout/type controls, language workflow, and the record component. Read [site-map.md](references/site-map.md) for routes and the map's factual boundaries. For Notes writing or a new article, also read [notes.md](references/notes.md).

Preserve the owner's factual boundaries. Do not invent work results, images of their work, personal stories, addresses, travel, publications, or roles. An editorial illustration can identify a record but must not be presented as a research figure or project screenshot. Keep team awards identified as team awards. Keep original PDF files unmodified and preview them with the local PDF.js viewer.

Current direction: compact clear typography, generous but purposeful space, a selective Home, separate Work and Notes, About with one canonical experience record set reached through cities and institutions, ordinary scrolling, contact options opening in place, and a restrained persistent music corner. Images should adapt to light and dark backgrounds. These are design decisions to assess against new user feedback, not a fixed template.

For layout corrections, change the shared `site.css` tokens and the owning component rule. Avoid adding another late override for a margin, font size, or page edge that already has a shared control. For substantive About copy, edit paired `zh`/`en` values in `about-content.mjs`; `check.mjs` checks completeness. The Traditional Chinese page is generated from Chinese. Keep About's personal note and the compact three-cover shelf together. The shelf should follow the owner's supplied 25 September image: overlapping real sleeves on a pale line, with a spreading hover animation and readable titles. The large network represents connected ways of thinking; it is not a literal five-node diagram or a claim about the owner's research. Write the vulnerable personal passage as continuous prose. The named emotions were examples, not categories; do not bring back an eight-card or eight-photo classification. Preserve the tentative “怪人” thought as the owner's uncertainty. Study, experience, honours, credentials, and review live in the separate factual records below. Treat this as a working design, subject to the owner's visual feedback.

When editing, build with `node website/build.mjs`, check with `node website/check.mjs`, and inspect affected routes in the browser at desktop and narrow widths. The tw edition is generated by opencc-js conversion of the zh render — write source copy in simplified Chinese and let the build convert; `check.mjs` fails if simplified characters, wrong `html lang` codes, or missing icon files reach the output, so treat those failures as regressions in the generation pipeline. State which parts were actually verified. Ask the owner only for missing personal facts or a design choice that materially changes the result; make other reversible improvements directly.
