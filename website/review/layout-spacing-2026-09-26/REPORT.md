# 版面間距修正 · 2026-09-26

這輪接續使用者提供的「About 文字結尾 → 工作台」截圖。前一轮的文字／字級檢查沒有充分處理實際版面的留白；此次調整分區、欄距、圖案佔位及容器間距。About 文案與內容順序保持不變。

數據來自實際元素邊界；包含文字行框，並非字形像素間距。手機工作台數值也包含其介紹內容，不是單純 padding。音樂說明保留可容納較長曲名的行高，避免選擇唱片時下方內容來回跳動。

## 結構上的修正

- 移除末尾的 Section rhythm normalization 補丁，把間距交回各區塊既有樣式與根變數。
- 分隔線前後分別由 `--section-before` / `--section-after` 控制：桌面 40/24px、700px 以下 32/20px。
- 個人區容器的底部 padding 歸零；音樂到記錄的距離由下一區的 margin 管理，避免外層容器暗中再加空白。
- 地圖未展開機構時，不保留機構列表需要的 20px 空白；該空間由實際出現的機構列表標題負責。
- 首頁文字區移除額外的手機左右內縮、重複的頁尾 margin；文字與其他區域對齊。
- Work 分組、News / Notes 頁尾、文章章節、一般頁頭與詳情頁尾使用對應的共用間距角色。個人區／工作台與文章左右欄使用有上限的欄距。
- 小插畫在手機上放在工作台標題旁，介紹文字仍用完整寬度，不額外擠出一整行圖案空間。

共用關係與單一間距責任寫入 [architecture.md](../../architecture.md#layout-spacing-and-ownership)，project skill 也加入「檢查頁面中段交界、計算疊加後留白」的要求。
